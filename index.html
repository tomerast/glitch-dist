How it works

Deterministic, not magic.

No machine learning, no cloud. Glitch learns your habits from local app and input-source usage, then sets the input source the moment focus changes.

1

You focus an app

Glitch notices foreground application changes through standard macOS or Windows APIs — nothing about what you type.

2

It resolves the input source

It looks up the keyboard input source you usually leave on for that app, learned from local usage or set by you as an app rule.

3

It switches before you type

Glitch asks the system to switch the input source and verifies it took effect. Your manual changes always win.

Local by design

It never reads what you write.

Glitch is built so it can't spy on you. In this version there is no code that observes keystrokes, and no network code at all.

No typed text

No typed text is observed, stored, or displayed. No Input Monitoring permission is requested.

No network

No telemetry, no update pings, no servers. Normal runtime works fully offline.

No clipboard, URLs, or titles

No clipboard access, and no window titles, URLs, document names, or contact names are read or saved.

Your data stays here

App rules and aggregate usage stay in your local Glitch data folder on macOS or Windows — yours to inspect or delete.

Get Glitch

Choose your platform.

Both private-alpha builds are unsigned. The installers require checksum verification and leave operating-system security protections enabled.

macOS 14+

Paste this into Terminal, or download the DMG and drag Glitch into Applications.

$ curl -fsSL https://raw.githubusercontent.com/tomerast/glitch-dist/main/install.sh | bash
  • Requires the SHA-256 corruption check before installing.
  • Installs Glitch.app to your Applications folder.
  • Leaves Gatekeeper and quarantine enabled.
  • Enables launch at login and starts the app.
Download the DMG
Unsigned build: follow the explicit macOS Open Anyway prompt if shown. The installer does not bypass it.

Windows 11

Paste this into Windows PowerShell or PowerShell 7. It installs per-user, with no administrator access required.

PS> & ([scriptblock]::Create((irm https://raw.githubusercontent.com/tomerast/glitch-dist/main/install-windows.ps1)))
  • Requires the ZIP's SHA-256 corruption check.
  • Installs under LocalAppData\Programs\Glitch.
  • Adds Start Menu and launch at sign-in shortcuts.
  • Does not call Unblock-File or suppress SmartScreen.
Download the Windows ZIP
Unsigned build: Windows may warn before launch. Review the publisher information and proceed only if you trust this private-alpha source.
